Each release is preserved as a standalone HTML snapshot in GitHub. Release times below are recorded from the corresponding GitHub deployment commits, shown in Brussels local time. Open an archived snapshot to review it. To restore it as the active version, replace the corresponding environment's index.html with that snapshot and commit the change. Browser-local edits are not part of these snapshots; export JSON separately to preserve those records. GitHub commit history additionally preserves every deployed change.
